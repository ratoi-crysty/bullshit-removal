# Every Revision is a Draft until an Admin publishes it

Detection, Recordings and hand-written edits all produce Drafts; nothing reaches Members' extensions until an Admin publishes it, even when Verification passed. A Rule with the wrong click target can Accept consent instead of Declining it, and Verification can confirm the Obstruction is gone but not which answer the Site recorded. The Admin review screen is built around the Verification Report (before/after screenshots, per-check results).

## Consequences

- Throughput of new Rules is bounded by Admin review time.
- Revisions are immutable, so rolling back is publishing an earlier Revision.
- Open for later: letting a Member's own Drafts apply in their own extension before approval.
